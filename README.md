# DumboRC Info

Guides for the **DumboRC DDF-350** 10-channel 2.4 GHz pistol-grip radio (also sold as the Amewi
DDF-350) and the DumboRC receivers that work with it: specifications, every menu function, setup
steps for crawlers and scale trucks, gyro, 4WS, winch and lights, firmware updates and community
mods.

| Guide | What's in it |
|---|---|
| [DDF-350 Transmitter](docs/ddf-350.md) | Specifications, controls and channels, full menu reference, firmware history, reviews |
| [Receivers](docs/receivers.md) | Every compatible receiver compared (P4FM/P6F/P6FP/P6DC/P10F/P16FG, X6F/X10F, XRDC), bind-key functions, light receivers and modules |
| [Setup Guide](docs/setup-guide.md) | Power, binding, wiring, directions and travel, fail-safe, gyro, 4WS, winch, cruise, wiper, lights, and setup recipes |
| [Firmware and Modifications](docs/firmware-and-mods.md) | Official updates step by step, the ELynx community firmware mod, hardware upgrades and accessories |
| [Tips and Troubleshooting](docs/tips.md) | Practical tips and fixes for common problems |

Most details come from DumboRC's own manuals and product pages, which are in Chinese and have been
translated; each guide lists its sources. Setup values such as gyro gain are general RC practice —
adjust to your vehicle.
